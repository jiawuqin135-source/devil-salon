# 恶魔理发师 ✂️

一款大头 Q 版的反应小游戏：趁天使店长喝茶、看书或接电话时，长按偷偷改造顾客发型；黄色预警出现时立即松手。

<img src="cover.png" width="360" alt="恶魔理发师游戏封面">

## 游戏内容

- 12 关依次解锁，难度逐步提高，12 位顾客拥有不同的前后造型。
- 红发恶魔与金发粉裙天使，配有姿态动画、烟雾、星星和声音反馈。
- 倒计时、暂停、抓包失败、通关星级以及本机存档。
- 适配手机屏幕；网页支持添加到 iPhone 主屏幕。

## 本地运行

安装 Python 3 后，在仓库根目录运行：

```sh
python3 -m http.server 8000
```

浏览器访问 http://localhost:8000。请通过本地服务运行，避免直接双击 HTML 导致音效加载受限。

如已安装 Node.js，可运行 `node check-rules.cjs` 检查规则。

## 发布

GitHub Pages 可从 main 分支的 `/ (root)` 目录发布。
小红书上传使用仓库中的独立 ZIP，不要上传 GitHub 的整个源码压缩包。
